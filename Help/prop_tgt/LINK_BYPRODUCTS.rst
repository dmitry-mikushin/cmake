LINK_BYPRODUCTS
---------------

Files written by the link rule of a target, in addition to the target itself.

Specifies a semicolon-separated list of files that the link step of this
target produces as a side effect, for example a linker map file, or the
sources generated by a link step that elaborates a design.  Relative paths
are interpreted relative to the target's build directory.

With the :generator:`Ninja` generators the files are declared as outputs of
the link edge, so that other build steps can depend on them, and the edge is
marked ``restat``: a byproduct whose content did not change keeps its
timestamp and does not cause its dependents to be rebuilt.

This property is supported only by the :generator:`Ninja` generators.

Contents of ``LINK_BYPRODUCTS`` may use "generator expressions" with
the syntax ``$<...>``.  See the :manual:`cmake-generator-expressions(7)`
manual for available expressions.
